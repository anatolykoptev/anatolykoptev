profile page github.com/anatolykoptev. It holds no code, no build and no CI.

  contract work" sentence and the contact address are the owner's wording; do not rewrite or
  remove them. Facts and numbers match the oxfound.com home page: change them there first.
- `assets/*.svg` are generated by `assets/src/build_assets.py` (text converted to outlines, wide
  and narrow layouts, light and dark). Change the script and rebuild; do not edit the SVGs by hand.
- Project entries link to public repositories under github.com/anatolykoptev; check a link
  resolves before adding or changing it, and keep each description to what the repository does.
- Commits use Conventional Commits (`docs: ...`). There is no release process and no changelog.
